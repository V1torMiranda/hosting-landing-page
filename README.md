# hDC Host – Landing Page

Acesse o projeto: https://v1tormiranda.github.io/hosting-landing-page/

Projeto de estudos em front-end desenvolvido para prática de HTML e CSS.

A aplicação consiste em uma landing page institucional para uma empresa fictícia de hospedagem, apresentando serviços, planos e informações de contato, com foco em layout e responsividade.

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  

## ✨ Funcionalidades

- Estrutura de landing page institucional
- Seções de apresentação de serviços
- Exibição de planos e preços
- Formulários de contato e busca de domínio (layout)
- Layout responsivo para diferentes tamanhos de tela
- Utilização de Flexbox para organização do layout

## 🎯 Objetivo do projeto

Praticar conceitos fundamentais de desenvolvimento web front-end, incluindo:
- Estruturação semântica com HTML
- Estilização com CSS
- Layout responsivo com media queries
- Organização de layouts com Flexbox

## 📌 Observações

Projeto desenvolvido com fins educacionais, como parte dos estudos em front-end.
